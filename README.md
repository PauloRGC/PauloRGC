### 💰 Análise BACEN

Projeto de análise da influência da **taxa Selic sobre o mercado de crédito brasileiro**, considerando crédito para pessoas físicas e jurídicas.

Os dados foram coletados através da API do Banco Central, tratados em Python e utilizados para análise de indicadores como juros, crédito e inadimplência.

**Tecnologias:** Python • Pandas • API BACEN • BigQuery • Looker Studio

👉 https://github.com/PauloRGC/Projeto-semantix-bacen
